# پرامپت اجرایی فاز ۲۲ — Multi-Agent Commerce Orchestrator

فاز ۲۲ را به‌عنوان لایه ارکستراسیون محدود، قابل ممیزی و deterministic روی APIهای موجود Calibra پیاده کن؛ نه یک چت‌بات و نه Agent با دسترسی آزاد به DB. هر Agent هویت، scope، budget و وضعیت روشن داشته باشد. همه ابزارها فقط از Tool Registry نسخه‌بندی‌شده با schema، permission، risk class، dry-run، idempotency، rollback، approval و verification فراخوانی شوند. Agent Council اختلاف را با objective/policy/evidence صریح حل کند، نه prompt پنهان. mutation پرریسک نیازمند approval و Phase 7 step-up است. kill switch باید اجرای جدید را متوقف کند. UI فارسی RTL زیر Channels → Agentic Commerce → Orchestration باشد و هر بخش/کنترل مهم HelperTooltip داشته باشد. هیچ action تزئینی، metric جعلی، SQL/shell دلخواه یا bypass دامنه canonical مجاز نیست. تست‌ها باید registry confinement، approval، idempotency، conflict trace، retry/verification و tenant RLS را پوشش دهند.
