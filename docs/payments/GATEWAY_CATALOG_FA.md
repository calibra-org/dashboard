# کاتالوگ درگاه‌های پرداخت کالیبرا

این سند کاتالوگ گام ۱ و ۲ فاز پرداخت را ثبت می‌کند. درگاه‌های هدف: به‌پرداخت ملت، سداد، پارسیان، زرین‌پال، بیت‌پی، دیجی‌پی، اسنپ‌پی، ازکی‌وام، کارت‌به‌کارت و پرداخت در محل.

وضعیت «پیاده‌سازی‌شده» به معنی وجود Adapter واقعی است؛ وضعیت «stub» تا زمان دسترسی به مستندات رسمی پذیرنده و تست sandbox اجازه فعال‌سازی ندارد.
